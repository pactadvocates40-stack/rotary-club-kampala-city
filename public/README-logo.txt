HOW TO ADD YOUR ROTARY LOGO
============================

1. Get the official logo from Rotary's Brand Center:
   https://brandcenter.rotary.org  (log in with your My Rotary account)
   Download the "Master Brand Signature" or wheel-only mark as a PNG
   with a transparent background.

2. Rename the file exactly to:
   rotary-logo.png

3. Upload it into this same "public" folder in your GitHub repo
   (the same folder this text file is sitting in).

4. Commit the change. Vercel will redeploy automatically, and the
   app will pick up the logo immediately — no code changes needed.

You can delete this text file once your logo is uploaded.
